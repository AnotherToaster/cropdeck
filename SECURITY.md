# Security

cropdeck runs locally and makes no requests to the internet; the browser interface listens on
127.0.0.1 only. If you find a security problem
anyway - for example a crafted image or CSV that makes it write outside its output folder -
please report it privately to **cropdeck@dr-dev.ch** rather than in a public issue.

You will get an answer within a week. Only the latest release is supported.
