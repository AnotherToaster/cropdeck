# Assets

| file | what |
|---|---|
| `icon.svg` | the cropdeck icon: a card inside crop marks (64 × 64 viewBox) |
| `logo-light.svg` / `logo-dark.svg` | icon + wordmark, for light and for dark backgrounds - generated by `tools/wordmark.py` from `icon.svg`, do not edit by hand |

Colours: teal `#0F766E` (card, "deck"), light teal `#5EB8AE` (card details; "deck" on dark), amber
`#F59E0B` (crop marks), text `#1F2937` on light and `#F3F4F6` on dark backgrounds. The wordmark is
set in Inter Bold (SIL Open Font License), converted to outlines.

Original artwork made for this project; it deliberately uses no trading-card game's imagery or colours.
